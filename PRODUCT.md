# Shrutik’s Internet Home

## Platform
web

## Stack
React, Vite, JSX, Tailwind, React Router, Motion and Lucide. Local JSON and Markdown; no backend.

## Purpose and constraints
A personal digital home for exploring projects, ongoing learning, original writing and life off-screen. AGENTS.md is the implementation contract. Preserve keyboard, wine, playful experiments, X and playlist configuration, honest contact delivery, accessibility and mobile support. Unknown personal content stays explicitly marked as sample content. Existing résumé and original HTML are supplied evidence; preserve originals.
